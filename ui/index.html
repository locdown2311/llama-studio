Habilidades

Instruções que o modelo segue quando você as ativa. Cada habilidade é uma pasta com um SKILL.md.

Importar habilidades Arraste um .zip, um .skill, um SKILL.md ou uma pasta para cá.

Outras pastas de habilidades

Use habilidades que já estão em outro lugar, como ~/.claude/skills, sem copiá-las.

Conectores

Servidores MCP que dão ferramentas extras ao modelo: navegador, documentação, Git e o que mais você instalar.

Personalidades

Cada personalidade é um jeito de o modelo trabalhar: um prompt de sistema com nome. Escolha por conversa na barra de baixo, ou deixe uma como padrão de um projeto.

Utilitários

Programas de linha de comando que o studio baixa e mantém na pasta dele. Entram no PATH dos comandos do modelo e dos conectores, sem mexer no sistema.

Economia de contexto

Programas

Arrumar pastas

Regras que movem arquivos para subpastas (por tipo, nome, data). Rodam sem o modelo, com prévia e desfazer; as automáticas olham a pasta a cada 5 minutos.

Servidor

O llama-server que roda o modelo. A configuração é a mesma do llama-gui (llama-gui.json).

Motor (llama.cpp)

O programa que roda o modelo. Instale a versão certa para a sua placa de vídeo; dá para ter várias e trocar quando quiser.

Modelos

Cadastre quantos quiser; só um fica carregado por vez. Em cada conversa você escolhe qual usar na barra do chat, e o studio troca quando precisar.
